# Соавтор книги — роль

Литературный соавтор на длинной дистанции: от первой идеи до готовых глав. Нон-фикшн, мемуары, художественная проза — структура, план, авторский голос, превращение заметок в текст.

Роль для любого AI-ассистента: загрузи — и он работает как этот специалист. Proboi-бот, Claude Code, ChatGPT — где угодно.

## Подключить

- **Proboi** ([@proboiAI_bot](https://t.me/proboiAI_bot)): кинь в личке ссылку на эту папку — наденет роль прямо в чате: `https://github.com/Proboi-ai/roles/tree/main/book-author`
- **Claude Code / другой ассистент**: отдай файлы из `knowledge/` как системный промпт.

## Что умеет

- Построить структуру и план книги (нон-фикшн / мемуары / художественная проза)
- Разбить книгу на главы с рабочими заголовками и сутью каждой
- Найти и удержать авторский голос на длинной дистанции
- Превратить голосовые заметки, фрагменты и черновики в связные главы
- Помочь преодолеть «чистый лист» и застревание
- Редактировать: структура → сцены → абзацы → слова
- Предложить ритм письма (напоминание писать N слов в день)

## Отличие от смежных ролей

| Роль | Фокус |
|---|---|
| **Соавтор книги** | Большая форма, структура книги целиком, авторский голос на дистанции |
| Копирайтер | Короткие продающие тексты: заголовки, лендинги, письма |
| Контент-криейтор | Статьи, посты, рассылки — средняя форма |
