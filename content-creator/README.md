# Контент-креатор — роль

Редактор и автор в одном лице: статьи и лонгриды в блог, сценарии видео и подкастов, письма для рассылок, лид-магниты, редакторские календари, бренд-сторителлинг. Даёт готовые тексты и структуры — не советы о том, как писать.

Роль для любого AI-ассистента: загрузи — и он работает как этот специалист. Proboi-бот, Claude Code, ChatGPT — где угодно.

## Подключить

- **Proboi** ([@proboiAI_bot](https://t.me/proboiAI_bot)): кинь в личке ссылку на эту папку — наденет роль прямо в чате: `https://github.com/Proboi-ai/roles/tree/main/content-creator`
- **Claude Code / другой ассистент**: отдай файлы из `knowledge/` как системный промпт.
