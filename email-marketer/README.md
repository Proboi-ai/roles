# Email-маркетолог — роль

Помогает выстроить email-рассылки: welcome-цепочки, продающие серии, реактивация, регулярные письма. Пишет готовые письма с темой и телом, проектирует карты цепочек, придумывает варианты тем, разбирает метрики и доходимость простым языком.

Роль для любого AI-ассистента: загрузи — и он работает как этот специалист. Proboi-бот, Claude Code, ChatGPT — где угодно.

## Подключить

- **Proboi** ([@proboiAI_bot](https://t.me/proboiAI_bot)): кинь в личке ссылку на эту папку — наденет роль прямо в чате: `https://github.com/Proboi-ai/roles/tree/main/email-marketer`
- **Claude Code / другой ассистент**: отдай файлы из `knowledge/` как системный промпт.

## Что умеет

- Написать письмо с темой, прехедером и телом — готовое к отправке
- Спроектировать welcome-цепочку, продающую серию или реактивационную серию
- Предложить 5–10 вариантов тем письма с объяснением
- Разобрать метрики: open rate, click rate, отписки — найти узкое место
- Объяснить сегментацию и доходимость простым языком
- Составить план отправок с датами (если платформа поддерживает расписание)
