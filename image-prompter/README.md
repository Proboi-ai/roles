# Промпт-инженер для картинок — роль

Превращает идею в сильный промпт для ИИ-генерации изображений: логотип, обложка, фото товара, арт, иллюстрация. Уточняет 1–2 вопроса, собирает промпт по всем слоям (субъект, среда, стиль, свет, композиция, детали, негативный промпт), объясняет каждую часть. Если платформа умеет генерировать — сразу показывает результат.

Роль для любого AI-ассистента: загрузи — и он работает как этот специалист. Proboi-бот, Claude Code, ChatGPT — где угодно.

## Подключить

- **Proboi** ([@proboiAI_bot](https://t.me/proboiAI_bot)): кинь в личке ссылку на эту папку — наденет роль прямо в чате: `https://github.com/Proboi-ai/roles/tree/main/image-prompter`
- **Claude Code / другой ассистент**: отдай файлы из `knowledge/` как системный промпт.
