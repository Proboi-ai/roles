# Справочник SEO-специалиста

Рабочие шпаргалки: типы запросов, on-page чек-лист, структура заголовков, перелинковка, техническая база простым языком, локальное SEO, Яндекс vs Google.

---

## Типы запросов и интент

**Интент** — что человек хочет сделать, когда набирает запрос. Это важнее частоты: если страница не отвечает на интент, она не встанет в топ, даже с идеальным текстом.

| Тип | Что хочет человек | Примеры | Какой формат страницы |
|---|---|---|---|
| **Информационный** | Узнать, разобраться | «как выбрать ноутбук», «что такое ипотека» | Статья, гайд, FAQ |
| **Навигационный** | Найти конкретный сайт/бренд | «вконтакте войти», «wildberries личный кабинет» | Главная или брендовая страница |
| **Коммерческий** | Сравнить, выбрать перед покупкой | «лучший антивирус 2024», «сравнение смартфонов» | Обзор, рейтинг, сравнение |
| **Транзакционный** | Купить, заказать, скачать | «купить наушники sony», «заказать пиццу москва» | Карточка товара, каталог, лендинг |
| **Локальный** | Найти рядом | «стоматология рядом», «кофейня на арбате» | Страница адреса, карты |

**Правило:** смотри, что уже стоит в топе по нужному запросу. Если там только статьи — не ставь лендинг и наоборот. Поисковик уже «решил» какой тип контента отвечает на этот интент.

## On-page чек-лист (страница за страницей)

### Title (заголовок страницы)
- Длина: **50–60 символов** (Google), до **70** (Яндекс) — не обрезается в выдаче
- Главный ключевой запрос — в начале
- Уникальный для каждой страницы
- Читается как человеческое предложение, не набор слов через запятую
- Для коммерческих — добавь выгоду или CTA: «Купить», «Цены», «В Москве»

**Было:** `SEO оптимизация сайта, SEO продвижение, раскрутка сайта`
**Стало:** `SEO-продвижение сайта в Москве — рост трафика за 3 месяца`

### Description (мета-описание)
- Длина: **120–160 символов**
- Не влияет напрямую на позиции, но влияет на CTR (кликабельность сниппета)
- Объясняет, что человек найдёт на странице, содержит призыв к действию
- Уникальный для каждой страницы

### H1 — главный заголовок страницы
- **Один** на странице
- Совпадает по смыслу с title, но может быть другим по формулировке
- Главный запрос — естественно, не «вбит» насильно

### H2–H3 — подзаголовки разделов
- Структурируют текст, помогают скиммингу (чтению по заголовкам)
- Хорошо включать смежные запросы и вопросы («Как...», «Почему...», «Сколько стоит...»)
- Не злоупотреблять — заголовок на каждые 2 предложения это уже слишком

### Текст страницы
- Отвечает на запрос полно, но без воды ради «нужного объёма»
- Ключевые слова — естественно, не через запятую
- Первый абзац — суть ответа, не «лирическое вступление»
- Для информационных: структура (что, почему, как, итог)
- Для коммерческих: выгоды, цена, условия, доверие (отзывы, гарантии)

### Изображения
- `alt`-текст: описывает что на картинке + можно добавить ключ, если уместно
- Имена файлов на латинице и описательные (`red-sneakers-nike.jpg`, не `IMG_0042.jpg`)
- Размер — оптимизирован (WebP или сжатый JPEG/PNG)

## Структура заголовков — шаблон

```
H1: [Главный запрос + суть страницы]
  H2: [Раздел 1 — смежный вопрос или подтема]
    H3: [Подраздел — детализация]
    H3: [Подраздел]
  H2: [Раздел 2]
    H3: [Подраздел]
  H2: [Раздел 3 — FAQ или итоги]
```

Пример для страницы «как выбрать ноутбук для учёбы»:
```
H1: Как выбрать ноутбук для учёбы: полный гайд 2024
  H2: На что смотреть в первую очередь
    H3: Процессор и оперативная память
    H3: Время автономной работы
  H2: Ноутбук для учёбы: какой бюджет нужен
  H2: Популярные ошибки при выборе
  H2: Часто задаваемые вопросы
```

## Перелинковка (внутренние ссылки)

**Зачем:** передаёт «вес» между страницами, помогает поисковику понять структуру сайта, удерживает пользователя.

**Принципы:**
- С популярных/сильных страниц ставь ссылки на важные, но менее известные
- Анкор (текст ссылки) — описательный, не «нажмите здесь» и не голый URL
- Каждая важная страница должна быть достижима не более чем в 3 клика от главной
- Похожие статьи / категории — связывай тематически, не хаотично

**Хаб-и-спица (Hub & Spoke):** для блогов и разделов удобна схема «главная тема → подтемы»:
- «Хаб»-страница о широкой теме (например, «SEO для малого бизнеса»)
- «Спицы» — узкие статьи (title-теги, скорость сайта, локальное SEO) со ссылками на хаб и обратно

**Что НЕ делать:**
- Ссылки ради ссылок — каждая должна быть полезна читателю
- Слишком много ссылок в одном абзаце — снижает доверие
- Битые ссылки — проверяй регулярно

## Техническая база — простым языком

Технические факторы не продвигают сами по себе, но их отсутствие мешает. Это фундамент.

### Скорость страницы
- Медленный сайт = плохие позиции + люди уходят до загрузки
- Проверить: [PageSpeed Insights](https://pagespeed.web.dev/) — покажет оценку и что конкретно тормозит
- Основные проблемы: тяжёлые картинки (решается сжатием и WebP), лишние плагины, отсутствие кэширования
- **Core Web Vitals** (CWV) — метрики Google: LCP (скорость загрузки главного контента), INP (отклик на клики), CLS (прыжки контента при загрузке). Всё это есть в отчёте PageSpeed.

### Мобильная версия
- Большинство поиска — с телефона. Google индексирует именно мобильную версию (mobile-first indexing)
- Проверить: [Mobile-Friendly Test](https://search.google.com/test/mobile-friendly) или просто открой на телефоне
- Текст должен читаться без зума, кнопки — нажиматься пальцем, не перекрываться

### Индексация
- Поисковик должен найти страницы и добавить их в базу (индекс)
- Проверить в Google Search Console: раздел «Индексирование страниц»; в Яндекс.Вебмастере: «Индексирование → Страницы в поиске»
- Частые причины, почему страница не индексируется: закрыта в `robots.txt`, стоит тег `noindex`, нет в sitemap, мало ссылок на неё
- `sitemap.xml` — файл-карта сайта для поисковиков, должен быть актуальным и сданным в консоли

### robots.txt
- Файл инструкций для поисковых роботов: что можно сканировать, что нет
- Опасен: случайная строка `Disallow: /` закрывает весь сайт от индексации. Проверять осторожно.
- Проверить: открой `твойсайт.ru/robots.txt` в браузере

### HTTPS
- Сайт должен работать по HTTPS (замочек в браузере), не HTTP
- Без HTTPS Google показывает предупреждение «небезопасно», а это снижает CTR и доверие

### Дубли страниц
- Одинаковый контент на разных URL — проблема. Поисковик не знает, какую версию показывать
- Частые случаи: `сайт.ru/страница` и `сайт.ru/страница/` (со слешем), www и без www, HTTP и HTTPS
- Решается редиректами (301) и тегом `canonical`

## Локальное SEO

Для бизнеса с физическим адресом или работой по городу/региону.

### Яндекс Бизнес и Google Business Profile (GBP)
- Зарегистрируй и заполни карточку полностью: адрес, часы работы, телефон, сайт, категория, фото
- Карточки попадают в карты и в локальный блок выдачи («пакет карт»)
- Отвечай на отзывы — это сигнал активности

### NAP-консистентность
- NAP = Name, Address, Phone (название, адрес, телефон)
- Они должны быть **одинаковыми** на сайте, в картах, в каталогах и справочниках
- Разные написания адреса («ул. Ленина, 5» и «Ленина д.5») путают поисковики

### Геозапросы
- Для локального трафика: добавь на страницы город/район там, где это уместно и естественно
- Отдельные страницы под разные города — только если есть уникальный контент для каждого, не клоны

### Справочники и каталоги
- Разместись в основных: 2ГИС, Яндекс Справочник (= Яндекс Бизнес), Zoon, Otzovik, профильные каталоги отрасли
- Следи за актуальностью данных

## Яндекс vs Google — кратко

| | **Google** | **Яндекс** |
|---|---|---|
| **Основной инструмент** | Google Search Console | Яндекс.Вебмастер |
| **Аналитика** | Google Analytics 4 | Яндекс.Метрика |
| **Карты/локальное** | Google Business Profile | Яндекс Бизнес / 2ГИС |
| **Факторы ранжирования** | Ссылки важны, E-E-A-T, CWV | Поведенческие факторы важнее ссылок |
| **Коммерческие запросы** | Строже к YMYL (деньги/здоровье) | ИКС (индекс качества сайта), региональность |
| **Апдейты** | Публичные анонсы, раз в месяц-квартал | Частые, часто без анонсов |
| **Скорость индексации** | Быстрее для авторитетных сайтов | Бывает медленнее, особенно новый сайт |

**Главная разница на практике:**
- В Яндексе **поведенческие факторы** (как пользователи ведут себя на сайте: сколько смотрят, возвращаются ли в выдачу) влияют заметно сильнее. Хороший контент, который удерживает, — это SEO для Яндекса.
- В Google **ссылочный профиль и E-E-A-T** (опыт, экспертность, авторитетность, доверие) важнее. Особенно для тем про здоровье, финансы, юриспруденцию.
- На **мобильных** оба поисковика приоритизируют мобильную версию сайта.
- Для **локального бизнеса** в России 2ГИС часто важнее Google Maps.

**Если нужен рост в обоих:** начинай с качества контента и технической базы — это работает везде. Потом адаптируй под особенности каждого.
